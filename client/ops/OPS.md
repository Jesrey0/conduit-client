# Conduit agent workflow

Use Conduit as the remote hands and keep disposable orchestration artifacts in
the agent sandbox. The preferred interface is one persistent `Conduit` SDK
instance per workflow.

## Orientation

Before substantive work, read `client/README.md`, the target project's
instructions, and the relevant overlay. Confirm the assigned workspace, current
Git status, and recent history. Preserve pre-existing changes.

```python
async with Conduit(workspace="conduit-local") as c:
    workspace = await c.workspace.current()
    status = await c.git.status()
    history = await c.git.log(limit=8)
```

Bind the workspace ID at client creation. A `Conduit` instance is the unit of 
workspace isolation; create a new instance for a different project or parallel 
worker.

## Tool hierarchy

```text
search -> c.files.read
c.files / c.git tools
c.terminal.execAsync + c.terminal.attach
```

## Mutation

- Use `c.files.edit` for bounded text substitutions.
- Use `c.files.write` with `base_hash` for whole-file replacement.
- Use `c.files.batch` for coordinated multi-file changes.

Fetch current hashes with `c.files.readMulti` before applying broad mutations.
Mutation safety relies on dry-run previews, optimistic-concurrency hashes, and
idempotency keys. Idempotency keys are auto-generated by the SDK; a replayed 
key returns the original response.

## Validation

After mutation, run the project's own validation commands. Prefer 
`c.terminal.execAsync` + `c.terminal.wait` for longer builds/tests.

```python
started = await c.terminal.execAsync("npm", ["test"], timeout_ms=600_000)
final = await c.terminal.wait(started["processId"], timeout_s=180)
print(f"Exit code: {final['exitCode']}")
```

## Git

Stage explicitly with `c.git.add(["path"])`, verify the staged diff with 
`c.git.diffStaged()`, then commit with `c.git.commit("message")`. Commit only 
intentional project changes; never commit temporary workflow artifacts.

## Summary

End each task with:
- what was changed (exact files/ids);
- validation result;
- commit hash;
- repository status.

## Script versus command execution

Use `terminal.exec` only for short direct executable/argument vectors. Switch to `terminal.runScript` when code spans multiple lines, embeds JSON/source blocks, needs heredoc-like content, or approaches the per-argument length limit. Send source directly; avoid nested `bash -lc` wrappers and locally generated quoting layers. The SDK normalizes a leading-dot extension (`.py` to `py`) before calling the strict server schema.
